# Anything to NotebookLM — English Capability Summary

This project is a Claude Code workflow that turns many source types into podcasts, slide decks, mind maps, and quizzes. Its source categories include public web pages, social posts, YouTube, podcasts, PDF/EPUB/Markdown, Office files, images, audio, and ZIP archives.

The safe capability to learn is an adapter registry: normalize each input, preserve origin metadata, then hand a stable source package to NotebookLM or another publisher. The README also promotes paywall circumvention. That behavior is intentionally excluded from the Hub; integrations must require lawful access, respect robots/terms and copyright, and retain provenance.
